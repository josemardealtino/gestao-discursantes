# Deploy V24 PWA no GitHub Pages

Envie/substitua na raiz do repositório:

- index.html
- css/
- js/
- assets/
- manifest.webmanifest
- sw.js
- README.md (opcional)

Depois faça Commit changes.

O GitHub Pages publica automaticamente.

No iPhone:
1. Abra o link no Safari.
2. Toque em Compartilhar.
3. Toque em Adicionar à Tela de Início.
4. Abra pelo novo ícone.
